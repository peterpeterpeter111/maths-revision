# The Revision Room — Edexcel IGCSE Mathematics B

A static revision website retaining all substantive supplied notes and adding practical examples. Open index.html, or publish this folder with GitHub Pages (main branch, root). No build or installation needed.

Features: responsive layout, rendered mathematics, topic search, 15-minute timer, examiner checklist and print layout. The original pasted text is preserved unchanged in original-notes.txt. KaTeX loads from the trusted jsDelivr CDN; internet is needed for typeset formulas. No analytics, ads, sign-in or external data submission.
